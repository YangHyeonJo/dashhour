# DASHHOUR 테스트 시나리오

Pleos Connect 에뮬레이터에서 약 10분이면 핵심 동작을 확인할 수 있다. 핵심은 **시나리오 1**이다. 기어를 P로 바꾸면 주차 완료와 소요 시간이 자동으로 기록되고, D로 바꾸면 출차 팁이 나온다.

## 1. 테스트 환경과 설치

| 항목 | 내용 |
| --- | --- |
| 에뮬레이터 | Pleos Connect Emulator v2.1.0 (API 34, Automotive) |
| 설치 파일 | `apk/DASHHOUR_DASHHOUR_release.apk` (저장소 내) |
| 소요 시간 | 시나리오 1 약 5분, 전체 약 10분 |
| 필요 조작 | 에뮬레이터 Virtual Console의 기어 변경 (P/R/N/D) |

1. 에뮬레이터를 켜고 Pleos 홈 화면이 뜨길 기다린다.
2. APK 파일을 에뮬레이터 화면 위로 끌어다 놓는다. 또는 `adb install apk/DASHHOUR_DASHHOUR_release.apk`.
3. 하단 바의 ⊞(앱 목록) → **DASHHOUR**.
4. 시작 전 기어가 **P**인지 확인한다 (화면 왼쪽 위 P R N D 표시).

앱 오른쪽 아래 **데모** 버튼을 누르면 검수용 콘솔이 열린다. 시나리오(A 타임스퀘어 / B 에버랜드 / C 대학병원), 재생 속도(1·5·10배), 기어 신호 출처(**시나리오** / **차량 (Pleos)**)를 고른다. 거리와 차속은 시나리오 데이터로 재생되고, 기어는 **차량 (Pleos)** 모드에서 Vehicle SDK 실제 신호를 쓴다.

## 2. 시나리오 1 (핵심) — 기어 신호로 주차 완료·출차

스마트폰이나 범용 AI가 알 수 없는 차량 신호(기어 P)로 주차 완료를 스스로 알고, 그 순간 소요 시간을 기록하는지 확인한다. 상황: 토요일 14:30, 영등포 타임스퀘어로 출발.

| No. | 조작 | 기대 결과 |
| --- | --- | --- |
| T1 | 데모 → 신호 출처 **차량 (Pleos)**, 시나리오 **A · 타임스퀘어** 선택 후 닫기 | 출발 전 화면. 내비 30분 + 주차 진입 대기 25분 → 차에서 내리는 시각 **15:25** |
| T2 | **그대로 출발** | 음성 안내(또는 자막)와 함께 주행 대기 화면 |
| T3 | Virtual Console에서 기어 **D** | 주행 화면으로 바뀌고 남은 거리가 줄어든다. 화면 버튼은 눌리지 않는다 |
| T4 | 기다리기 (남은 거리 1km) | 진입 경로 팁을 음성·자막으로 한 번 안내 |
| T5 | 기다리기 (주차장 진입) | 층·구역 팁 표시. 재생이 멈추고 기어 P를 기다린다 |
| T6 | 기어 **P**로 바꾸고 5초 기다리기 | 주차 완료 화면. 진입~주차 **27분** 측정, **+10P**, 음성 팁 등록 안내 |
| T7 | **팁 등록하기 · +30P** | 팁 등록, 포인트 30점 추가 |
| T8 | 기어 **D** (또는 **R**) | 출차 화면. 출차 팁을 음성·화면으로 안내 |

T3에서 화면이 넘어가지 않으면 데모 콘솔의 신호 출처가 **차량 (Pleos)**인지 확인한다. 주행이 멈춰 있으면 콘솔의 **재생**을 누른다.

## 7. 알려진 제한

- 거리·차속·목적지는 시나리오 데이터다. 실제 차량 신호로 연동한 것은 기어(P/R/N/D)이고, NaviHelper·위치·음성 입력 SDK는 서비스 단계에서 붙인다.
- 에뮬레이터에 한국어 음성 엔진이 없으면 음성 안내 대신 자막만 표시된다.
- P단 음성 팁은 예시 문장으로 흐름을 보여준다. 등록한 팁과 포인트는 앱 안에만 저장되며 서버로 전송되지 않는다.
- 화면은 1600×720 기준이라 에뮬레이터 해상도에 따라 위아래 또는 좌우에 여백이 생길 수 있다.
